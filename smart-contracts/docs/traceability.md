# Stage 1 acceptance traceability

RFP v2 §4.3(1): every `AC-*` of Stage 1 mapped to named tests. Requirements:
[inference-contract-enhancements-rfp.md](inference-contract-enhancements-rfp.md). Stage 1 covers §3.4.1, §3.3.3 part A, §3.4.2, §3.4.3 and §3.6.2; Stage 2-only criteria are
not listed. Paths are relative to `smart-contracts/`; test names are the full `describe › it` chain.

Status:
- `covered` — named tests assert the criterion;
- `partial` — part of the criterion is checked here, the rest is named in the last column;
- `document` — the criterion is a written deliverable; the document is listed instead of a test.

22 criteria: 17 covered, 2 partial, 3 document.
