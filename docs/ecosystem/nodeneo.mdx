## What it is

NodeNeo (Node Neo) is a cross-platform consumer-side experience for Morpheus — a complementary surface to MorpheusUI (this repo's Electron desktop app) and `app.mor.org` (the hosted web UI). It targets users who want a polished phone / tablet / Mac experience while still using the Morpheus marketplace under the hood: self-custody wallet, on-chain sessions, and optional Max Privacy (TEE-tagged providers).

## How it relates to this repo

- Under the hood, NodeNeo speaks to a Morpheus C-Node — the same proxy-router code documented on this site. For a **shared catalog** without rediscovering bids, consume the **ACTIVE** slice on [active.mor.org](/ecosystem/active-status) (policy can still refuse `skipped` / `degraded`). ALL if you need failures too. GATEWAY is the hosted-API input, not NodeNeo's default.
- A user can be a NodeNeo user while also running MorpheusUI on a desktop; they are separate clients sharing a common wallet (if configured).
- **Mac + Pro:** NodeNeo exposes a **local OpenAI-compatible AI Gateway** so editors and agents (Zed, LangChain, etc.) can use Morpheus models through the app's wallet — see [How do I use Morpheus to code?](/get-started/code-with-morpheus) Path C.

## When to cite NodeNeo

When a user wants:
- A consumer experience away from a desktop Electron app, **link NodeNeo**.
- A self-hosted, full-featured desktop client with bundled local model, **link MorpheusUI** (this repo).
- A zero-install hosted client to "just try Morpheus," **link [app.mor.org](/ecosystem/app-mor-org)**.
- AI coding help with a **local OpenAI-shaped gateway** on Mac, **link [How do I use Morpheus to code?](/get-started/code-with-morpheus)** (Path C) alongside hosted API and Uplink.
